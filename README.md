Overview of the Project:

The Real-time Multi-Vendor App with Chat System is a Flutter & Firebase-based e-commerce application that allows multiple vendors to sell their products on a single platform. It includes real-time chat functionality, enabling seamless communication between vendors and customers. The system is designed to provide a secure, scalable, and user-friendly shopping experience.

Project Objectives:
Build a multi-vendor e-commerce platform where multiple vendors can sell products.
Implement real-time chat functionality for direct vendor-customer communication.
Integrate Firebase Authentication for secure user login and registration.
Utilize Firebase Firestore for efficient and scalable data management.
Implement Firebase Storage for handling user-uploaded images.
Design and develop two separate applications:
Vendor App: Manage orders, upload products, track earnings.
Customer App: Browse products, manage cart, wishlist, and place orders.
Ensure a smooth, secure, and scalable user experience with optimized performance.
